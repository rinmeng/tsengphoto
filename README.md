# tsengphoto

A modern photography portfolio platform built with Next.js, Supabase, and Shadcn UI. Professional event photography showcasing in Vancouver and Kelowna.

![tsengphoto](website.png)

## Documentation

Visit the [live site](https://tsengphoto.ca) to explore the portfolio.

## Tech Stack

Built with [Next.js 15](https://nextjs.org), [Supabase](https://supabase.com), [Shadcn UI](https://ui.shadcn.com), and [TypeScript](https://typescriptlang.org).
